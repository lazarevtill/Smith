# License status

No application-wide license is granted by this repository at present. The
initial source snapshot did not contain a verified root license grant, and this
refactor does not invent one. A public repository is not itself a license.

Existing per-file copyrights and third-party licenses remain in effect. The
selected original Smith UI markup and assets are recorded by exact bytes in
`vendor/smith-ui/SOURCE.json`. That manifest records provenance, not a new grant
of rights. The application owner still needs to select an application license
and confirm the scope of any original assets before distribution.

Fonts, Slint, Rust dependencies and Swift/MLX dependencies have their own terms.
The notices included in this repository are described in
`THIRD-PARTY-NOTICES.md`. Model weights are not included; model licenses must be
checked independently when obtaining and distributing a model.

No claim of distribution, signing, notarization or installer clearance is made.
