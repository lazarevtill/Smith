# Smith v0.1.0-alpha.1

First source-only development prerelease of the local Rust/Slint desktop refactor.

## Highlights

- Preserves the original native interface and assets, with compact chat actions
  and draft recovery instead of the oversized toolbar.
- Adds imported historical image and literal tool/result cards with bounded
  decoding, source validation and stale-navigation protection.
- Filters inference settings by platform and removes unsupported WSL2,
  winget and Windows startup controls.
- Keeps ordinary local access free of account/login screens.

## Downloads and compatibility

This release provides GitHub source archives only. No installable app package,
model weights or prebuilt inference runtime is attached. There are no binary
signing, notarization or all-platform runtime claims. Internal crate versions
are independent of the repository release tag.

## Known limitations

Windows owned-process/startup and secure-storage support remains incomplete.
Linux/Windows native dialogs and clipboard adapters remain incomplete. Actual
other-platform desktop lifecycle and GPU hardware verification are still pending.
The presence of CUDA, HIP/ROCm, SYCL, Vulkan, Metal or MLX configuration does not
establish execution or performance on a device. Model output quality is not
established by build success.

Use disposable profiles for development. Preserve original workspaces and keys;
this source release performs no automatic migration, installation or replacement.
Application-wide licensing has not been selected; existing third-party notices
remain applicable. See LICENSE-STATUS.md and docs/PLATFORM-READINESS.md in the source.
